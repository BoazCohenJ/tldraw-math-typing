# Contributing

## Layout
| Path | What it is |
|---|---|
| `src/rules.js` | Typing shortcuts: regex rules on the text before the caret; `/draw` and `//{…}` parsing; settings and migrations; hints; cheat sheet. No browser APIs. |
| `src/mathtools.js` | `/` commands: expression parser, evaluator, pretty printer; graph geometry (explicit and implicit curves, intersections, circle centres); shape geometry. No browser APIs. |
| `src/content.js` | Runs in tldraw.com pages (isolated world): watches typing, replaces text, hint card, live root bar, fonts, talks to `page.js` and the background. |
| `src/page.js` | Runs in the page itself (MAIN world) so it can use tldraw's editor: draws roots, fractions, bounds, equations, graphs and shapes as tldraw shapes. |
| `src/background.js` | Attaches to open tabs after install/update/permission; runs calculator commands (in `cas-worker.js` on Firefox, directly in the service worker on Chrome). |
| `src/fonts.js` | Generated by `tools/build-fonts.py`: inlined font subsets and which characters each covers. |
| `src/vendor/nerdamer` | nerdamer 1.1.13 (MIT) with one change: `build()` throws instead of compiling code (see THIRD_PARTY_NOTICES.md). |
| `src/popup.*` | The toolbar popup. |
| `scripts/build.mjs` | Builds `dist/firefox` and `dist/chrome` (with per-browser manifests) and their zips. |
| `test/unit` | Node tests, run with eval disabled as in browser extensions. |
| `test/e2e` | Browser tests on the real tldraw.com: Chromium (Playwright) and Zen/Firefox (Selenium + geckodriver). |
| `store/` | Store listings, privacy policy, screenshots and the script that makes them. |

## Workflow
1. `npm install`
2. Change things in `src/`, add a unit test for rule or calculator changes.
3. `npm test && npm run lint`
4. `npm run e2e:chrome` and, with Zen or Firefox and geckodriver installed, `npm run e2e:zen`.
   The Zen suite includes `worksheet`, which types five exam questions the way a student would; run
   it after any change to how Enter, drawing or commands behave.
5. Try it by hand: `npm run start:firefox`, or load `dist/chrome` unpacked.

## Fonts
`npm run fonts -- <tldraw fonts dir> <NotoSansMath> <NotoSans 500> <NotoSerif 500> <NotoSans 700> <DejaVuSans-Bold>`
regenerates `src/fonts.js` after adding shortcuts with new symbols. The tldraw fonts are the `woff2`
files tldraw.com loads; the others come from Google Fonts and the DejaVu releases.

## Releases
1. Update `version` in `package.json` (the build stamps it into both manifests) and `CHANGELOG.md`.
2. Commit, tag `vX.Y.Z`, push the tag: the release workflow builds both packages and attaches them to
   a GitHub release.
3. Upload `math-typing-firefox-X.Y.Z.zip` to addons.mozilla.org and `math-typing-chrome-X.Y.Z.zip`
   to the Chrome Web Store (see `store/firefox.md` and `store/chrome.md`).
